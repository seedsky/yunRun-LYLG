# 已确认的产品决策

- Windows 便携 ZIP，源码与内置 Python。EXE 自行构建方式放 README。
- 便携包按“启动入口／程序文件／使用说明”分组，首次运行生成“用户数据”；不设置系统隐藏属性，不移动用户旧版目录。
- 使用者已确认记录 isQualified：1 为有效（达标），2 为无效（不达标）；其他代码与服务器备注原因仍以实际返回和官方界面对照为准。
- 手机只读核对确认：详情 noQualifiedReason 是服务器不合格原因，直接展示，不解码猜测 remake；开始、服务器结束时间和 duration 分别展示，不互相推算。
- 手绘草稿实时显示累计距离、点数、最近一段、按当前配速估时和距起点距离；明确与生成后的最终预览不同，目标里程只在用户主动点击时采用草稿长度。
- 密码登录和抓包两种入口并存。候选 token 先单独 DPAPI 加密，后台读取学校和学号并验证任务后才切换；同账号保留密码，不同账号不继承原密码，失败保留原会话。
- 本次实测重新登录会使旧 token 失效；共用手机捕获的当前 token 可同时查询。不能把两种入口并存宣传为服务端保证两个独立登录会话永久有效。
- 本期单账号，允许退出换号；模块边界预留扩展，不提供批量账号操作。
- 先复用 token，失效后以保存的密码尝试登录一次；失败停下，由用户重试或抓包。
- 密码/token 保存为 Windows 当前用户绑定的加密文件；退出清除密码/token，保留账号名、设置和路线。
- 无密码的迁移备份包含账号/token/设置/路线，不含登录密码；分类选择导入，重名默认保留两份，也可覆盖或跳过。
- 独立工具无需账号；本地功能也仍在联网面板保留，两边共用逻辑。地图组件随包，底图可联网，断网可查看轮廓和绘制。
- 路线来源统一为随机、已有、历史、手绘；手绘直接使用工作台地图，保留文件导入导出。
- “生成并预览”合并；“仅预览”保留。“保存路线”仅收藏，不是执行条件。
- 临时预览可以直接执行，执行快照与预览一致。改参数保留旧图、标记过期并暂停执行，重新生成后恢复。
- 常用参数直接显示，其他折叠。默认以目标平均配速输入，分/秒分别填写，默认沿途起伏，可切换时长输入。
- 同屏工作台，日志可展开。B 为亮色，C 为暗色；默认跟随系统并记住手动选择。
- 底层学校/设备/协议配置放高级设置，不要求普通用户理解 INI。
- 演练可选，正式执行前自动校验；默认实时等待，快速模式放高级设置。
- 执行期间锁定路线和参数；停止先确认。关闭网页继续，关闭控制台退出。中断不续跑，保留确认进度和日志，提供历史查询。
- 抓包采用 Super Proxy 为主，先做手机到电脑连通性检测。面板提供每机匹配证书，不附旧证书；系统代理等待实机实验后决定。
- 服务器规则优先、显示来源与更新时间，缓存供本地参考；执行前必须重新获取。缺失字段明确标记，不把本地值说成实时规则。
- 单任务自动选择，多任务明确选择并记忆，失效重选。
- 中文维护型注释，面向实际使用和交给后续 AI 扩展，说明模块职责、输入输出与约束。
- 已先完成独立的登录链路验证；第一版构建与验收阶段不使用真实账号创建记录或上传轨迹。分歧集中报告，不在实现中逐项打断用户。

- 1.0.0 增加实际单文件 EXE 构建与隔离验收，单独交付 EXE 和内置环境 ZIP。EXE 资源使用 _MEIPASS，持久数据在 EXE 同级“云运动用户数据”。
- 用户表示真实提交已自行测试，本轮不再重复；不要求新 CA 安装及其他网络实测，跨电脑实测暂缓。
- GitHub 目标为用户新建的 seedsky/yunRun-LYLG，保留现有 MIT 许可证及 SpringSoap 署名；用 NOTICE 明确新增代码、上游和第三方范围，公开仓库不提交运行环境、APK 或任何个人数据。
