执行命令：`runtime\python.exe -X utf8 -m unittest discover -s tests -v`。

浏览器实际走通：亮/暗切换、参数过期禁用执行、重新生成、保存、仅预览、地图内手绘、子进程本地演练、页面刷新恢复、备份下载/导入/同名保留两份，以及无账号、无底图的独立工具。浏览器控制台未发现应用脚本错误。截图位于 docs/screenshots/。

抓包组件在隔离临时目录验证过代理启动、当前 CA 生成、公开证书下载与私有路径拒绝；仅进行了本机 loopback 检测，不能代替手机和校园网实测。控制台进程族终止子进程机制已自动验证。

## 自动验收范围

- Windows DPAPI 凭据保存/恢复、退出清除。
- 同种子复现、逐点配速起伏、临时预览不自动收藏。
- 参数冲突不自动改写、动态规则优先。
- 仅预览不改原文件、快照篡改与路径越界拒绝。
- 备份排除密码、选择性导入、同名保留两份。
- 登录失败不重试，失效 token 重新登录至多一次。
- 规则缺失来源明确、多任务不默认第一项。
- 子进程本地演练、快照一致性、中断不自动恢复。
- 浏览器检查亮/暗主题、生成预览、参数过期、路线库、备份、布局与独立工具。
- 发行包白名单、空白账号配置与个人数据排除。

## 留待用户实机验收

- 实际创建开始记录、实时分批发送、停止后的服务端状态、结束后的最终成绩。
- Super Proxy 在实际手机上的安装、校园网/热点/USB 连通性、CA 安装与目标 App 信任。
- 系统 Wi-Fi HTTP 代理是否被目标 App 遵循。
- EXE 构建产物；本期仅提供构建方法，正式交付是内置环境源码 ZIP。

## 兼容语义说明

服务器同时返回 raDislikes 与 raMinDislikes。第一版保留旧执行引擎较严格的打卡数量守卫，界面显示实际命中；没有把字段语义未经核实地放宽。随机生成默认经过全部点。

人脸开关与上传批次阈值在前期实测响应中缺失，UI 标记未确认；执行引擎保留原有兼容处理。出现明确人脸要求时停止自动流程。单次 20 分钟上限来自本地配置，不能标为服务器已确认。

沿用原几何算法，校验围栏与点位，没有新增道路通行性或建筑物避让判断。

## 预览版 4：USB 手机只读核对

已通过手机已有记录页面及官方 3.6.6 安装包的展示逻辑确认：不合格原因来自 noQualifiedReason，和 remake 编码没有直接翻译关系。原因字段已加入白名单与详情显示；缺失则提示未提供。记录列表明确标出开始／服务器结束／服务器列表时间，详情用时继续读取 duration。

31 项本地回归通过，现有只读详情测试增加了原因白名单与时间／用时不相互推算的检查。浏览器演示已实际显示无效详情及中文原因。USB 调试反向转发的手机到电脑 HTTP 请求与响应通过，测试端口已移除；没有改动手机代理、安装证书或创建跑步记录。

手机随后自动锁屏，本地保存 token 在只读请求中未通过认证，未重新登录。当前尚不能声称实时 API 与手机详情已逐字段对照；CA 信任及完整抓包仍需手机解锁后继续。详细范围和限制见 PHONE_VALIDATION.md。
