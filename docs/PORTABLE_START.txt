云运动 · 洛阳理工本地工作台（1.0.0）

请先把整个 ZIP 解压到可写目录，不要直接在压缩包内运行。

日常使用只需打开“启动入口”文件夹：
  启动联网面板.bat：登录、路线、任务、跑步记录。
  启动独立工具.bat：免登录生成、预览、手绘和保存路线。
  抓包备用登录.bat：需要抓包登录时使用。
  检查运行环境.bat：排查内置 Python 依赖，不联网。

“程序文件”集中保存源码、内置 Python、手机 APK 和维护文档。
“用户数据”首次运行后自动创建，保存本机设置、路线、日志及加密凭据。
请保留这些文件夹的相对位置，不要只移动启动脚本。
关闭网页不退出程序；关闭控制台才会退出。

从预览版 1／2 升级：
1. 先关闭旧版控制台，把新版解压到一个新目录。
2. 若要保留账号和路线，将旧版 data 文件夹复制到新版根目录，改名为“用户数据”。
   新版首次运行过时，先备份已生成的“用户数据”，再选择保留哪一份，避免覆盖新数据。
3. 在同一 Windows 用户下可继续解密旧凭据。跨电脑请使用面板“数据备份”导出／导入。
旧版目录不会被自动移动或删除。分享程序时，请勿分享“用户数据”。

记录状态：1＝有效（达标），2＝无效（不达标）；其他未知代码保留原值。
详细使用、维护、重新打包 ZIP 和自行构建 EXE：程序文件\README.md。

登录提示：抓包登录复用手机当前 token，本身不顶号；账号密码登录会顶号，自动密码重登同样如此。
EXE 的数据目录为程序旁“云运动用户数据”，ZIP 为顶层“用户数据”。
